# BingDesk 第一版规格

用户已授权创建 GitHub 仓库、实现、云端编译、测试和本机安装。账号 roy-xiong；独立公开仓库 bingdesk；不安装本机 Xcode，不在本机编译。

- 原生 Swift + SwiftUI 菜单栏应用，中文界面，macOS 13+，第一版 Apple Silicon arm64。
- 使用 Bing zh-CN 官方最近八张图片作为每日来源；使用 YanGN-ST/bing_wallpaper_archive 的索引与按年数据作为随机历史来源，并保留来源署名。
- 每日自动检查一次；启动与系统唤醒补检查；失败后可重试。用户当天手动换图后不被同日自动检查覆盖。
- 手动提供随机换图、恢复最新每日壁纸。并发操作串行，不出现旧请求覆盖新请求。
- 下载至磁盘并用 ImageIO 读取真实像素：宽至少 3840、高至少 2160；不放大，不降级到 1080p 或缩略图。
- 网络、JSON、HTTP、图片或壁纸设置失败均保留上一张；使用有限候选和超时，不能无限重试。
- 在主线程使用 NSWorkspace 为当前已连接屏幕设置壁纸；多屏失败尝试回滚已设置屏幕，不承诺其他 Mission Control 空间。
- 缓存保留最多最近 10 张且最多 200 MiB；不能删除任何显示器正在使用的文件。原图不加载进界面，界面只生成缩小预览。
- 保存已选图、每日成功检查时间和自动更新开关。提供登录时启动开关。
- GitHub Actions 执行测试、Release 编译、ad-hoc 签名与校验、DMG 封装，发布可下载产物。无需 Developer ID 或公证证书。
- 交付前验证 DMG、二进制架构/最低系统/签名、真实 4K、主机换图和失败保护；安装后检查菜单栏界面和登录启动能力。

## 实现边界

核心模块 WallpaperCore 负责纯策略、来源、下载与缓存。App 模块 BingDesk 负责 MainActor 状态、系统集成和 SwiftUI 菜单。项目无第三方运行依赖，不下载整个壁纸仓库。
